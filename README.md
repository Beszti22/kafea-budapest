# Kafea Budapest — Kávézó & Brunch (Tűzoltó utca)

Prémium kétnyelvű (HU/EN) weboldal és demó a budapesti **Kafea** kávézó és bruncholó számára.

## 📍 Helyszín & Fókusz
- **Cím:** 1094 Budapest, Tűzoltó utca 33. (Ferencváros / Semmelweis Klinikák M3 mellett)
- **Koncepció:** All-day brunch, 100% Arabica specialty kávék, helyben sült péksütemények, kutyabarát terasz.
- **Dizájn & Paletta:** Sárga és fehér napsütötte színek (`#FBBF24`, `#FEF08A`, `#FFFFFF`) mély pörkölt kávé kontraszttal (`#1C1917`), WCAG AA+ akadálymentességgel.

## ✨ Főbb funkciók
- **Kétnyelvűség (i18n):** Azonnali váltás magyar és angol nyelv között (`i18n.js`).
- **Interaktív Étlap:** Kategóriánként böngészhető kínálat (All-day brunch, Specialty kávék, Pékáru).
- **Asztalfoglalási űrlap:** Reszponzív, azonnali visszajelzést adó foglalási felület.
- **Optimalizált képek:** 100%-ban helyi, optimalizált WebP formátum a villámgyors betöltésért.
- **Készítette:** Besztweb Webstúdió
